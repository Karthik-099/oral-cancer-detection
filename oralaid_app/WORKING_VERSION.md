## 🚀 **HOW TO USE**

### **1. Start the Application**
```bash
cd /home/karthik/oral-cancer-detection/oralaid_app
python3 app.py
```

### **2. Access the System**
- **🌐 URL**: http://localhost:5000
- **👤 Login**: `admin` / `admin123`

### **3. Perform AI Diagnosis**
1. **Login** → Go to "AI Diagnosis"
2. **Enter Patient Info**: Name, age, gender, medical history
3. **Upload Image**: Select intraoral photograph (JPG/PNG)
4. **Click "Analyze"** → AI processes the image
5. **View Results**: 
   - **Original Tab**: See uploaded image
   - **LIME Tab**: Green areas support diagnosis
   - **GradCAM Tab**: Hot colors show AI attention
6. **Review Recommendations**: Clinical guidance based on risk level
7. **Save Notes**: Add clinical observations
8. **Print Report**: Generate professional report

### **4. Dashboard Features**
- **Statistics**: Total diagnoses, high-risk cases, success rate
- **Recent Cases**: Quick access to recent diagnoses
- **Quick Actions**: New diagnosis, Windows tool download
- **System Status**: AI model and system health
